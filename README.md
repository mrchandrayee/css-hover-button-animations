## Included effects

The video shows these eight effects in sequence. The original visible animation numbers are preserved:

1. **Animation 03 — Liquid Morph**
2. **Animation 04 — 3D Layer Drop**
3. **Animation 05 — Magnetic Center Reveal**
4. **Animation 06 — Neon Pulse Glow**
5. **Animation 07 — Diagonal Slicer**
6. **Animation 08 — Text Swap**
7. **Animation 09 — Border Draw**
8. **Animation 10 — Shifting Gradient**

## What is extracted vs recreated

The video displays a small CSS source pane beside each live button. The legible selectors, colors, transforms, pseudo-elements, keyframe declarations and transitions have been transcribed into the CSS snippets shown by the project. Some tiny or partially obscured values have been reconstructed where the recording does not make them fully readable.

The page layout, responsive behavior, navigation dots, previous/next controls and copy button are project additions to make all eight examples easy to explore in one runnable page.

## Run

1. Extract the ZIP.
2. Open `index.html` in any modern browser.
3. Hover over the demo button to see the selected animation.
4. Use the arrow buttons or dots to switch effects.
5. Click **Copy CSS** to copy the currently displayed CSS snippet.

No npm, build process, external dependencies or internet connection is required.
